# 기관 업무계획 수집 서버

광주·전남 행사레이더가 기관 자료를 서버에 저장하기 전에 공식 원본을 내려받는 서비스임.

- 광주시·5개 구청·전남도청·22개 시군의 공식 HTTPS 도메인만 허용함.
- `/download`는 PDF·HWP·HWPX·XLSX 원본을 반환하며 `/page`는 자료 게시판 HTML 조회용임.
- 두 경로 모두 24자 이상의 `COLLECTOR_TOKEN`을 이용한 서버 간 인증이 필요함.
- TLS 검증, 기관별 주소 검증, 같은 origin에만 세션 쿠키 전달, 파일 10MB 제한을 적용함.
- 실제 원본의 영구 보관과 월별 행사 검색은 행사레이더 서버 저장소가 담당함. 이 수집 서버의 메모리 캐시는 일시적인 다운로드 최적화임.
- 자료 미확보나 추출 실패를 행사 없음으로 판정하지 않음.

`node server.mjs`로 실행하며 `/health`에서 버전과 지원 기관 수를 확인할 수 있음.
